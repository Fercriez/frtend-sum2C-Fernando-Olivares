Contenido del Formulario
El formulario debe estar dividido en cuatro secciones claramente diferenciadas de forma visual, con
titulos de seccion que indiquen al usuario donde se encuentra.
Seccion A — Tipo de Solicitud y Datos del Evento

Tipo de solicitud (radio buttons: Reserva de mesa en el salon, Servicio de catering externo).
La seleccion de este campo determina que campos adicionales se muestran en la Seccion
B.
Fecha del evento o reserva (input date, requerido).
Hora de inicio (input time, requerido).
Duracion estimada del evento (select: 1 hora, 2 horas, 3 horas, 4 horas o mas). Solo visible
si se elige catering externo.
Nombre o descripcion del evento (input text, requerido solo para catering): ejemplo
"Cumpleanos de 50", "Reunion anual de empresa".
Tipo de evento (select, solo para catering: Casamiento, Cumpleanos, Evento corporativo,
Desayuno o coffee break, Otro). Si se elige "Otro", mostrar campo de texto adicional.
Lugar del evento (input text, requerido solo para catering): direccion donde se realizara el
servicio.
Seccion B — Datos de los Comensales
Cantidad de adultos (input number, minimo 1, maximo 200, requerido).
Cantidad de menores (input number, minimo 0, maximo 50).
Restricciones alimentarias presentes (checkboxes multiples): Vegetarianos, Veganos, Sin
TACC (celiacos), Sin lactosa, Alergias a frutos secos, Otras.
Si se marca "Otras", mostrar un textarea para detallarlas (maximo 200 caracteres, con
contador).
El grupo necesita menu infantil (checkbox). Si esta marcado, mostrar campo numerico para
indicar la cantidad.
Seccion C — Datos del Cliente y Preferencias
Nombre completo (input text, requerido).
Correo electronico (input email, requerido).
Confirmar correo electronico (input email, requerido).
Telefono de contacto (input tel, requerido).
Tipo de menu preferido (select: Menu degustacion, Menu clasico, Menu infantil
predominante, A definir con el chef).
Bebidas incluidas (checkboxes: Agua, Gaseosas, Vinos, Champagne, Sin alcohol). Al
menos una debe seleccionarse.
Necesita servicio de mozos (checkbox, solo para catering externo).
Necesita mobiliario: mesas y sillas (checkbox, solo para catering externo).
Como nos conocio (select: Redes sociales, Recomendacion, Busqueda web, Fue cliente
antes, Otro).

Seccion D — Observaciones y Confirmacion
Observaciones o pedidos especiales (textarea, maximo 350 caracteres, con contador de
caracteres visible).
Acepta que BuenSabor se contacte para confirmar disponibilidad (checkbox obligatorio).
Acepta los Terminos y Condiciones del servicio (checkbox obligatorio, con enlace a pagina
ficticia).
Acepta la Politica de Privacidad (checkbox obligatorio).
Botones de Accion
Boton principal "Enviar solicitud" (submit), centrado y con estilo destacado.
Boton secundario "Limpiar" (reset).
Enlace "Volver al inicio" que redirija a index.html.
Requisitos de Estilo y Accesibilidad
Los campos deben cambiar visualmente al recibir el foco (:focus): borde con color y sombra
suave.
Preparar las clases CSS "campo-error" (borde rojo) y "campo-ok" (borde verde) para ser
aplicadas en la Etapa 3.
Las cuatro secciones del formulario deben estar visualmente separadas: fondo diferente,
borde redondeado o titulo de seccion destacado.
El formulario debe estar centrado con un ancho maximo de 750 pixeles.
Diseno responsivo: en pantallas de escritorio algunos campos pueden mostrarse en dos
columnas; en dispositivos moviles todos los campos ocupan el ancho completo.
Todos los campos deben tener su etiqueta <label> asociada correctamente. Los campos
requeridos deben estar marcados con asterisco.
Los grupos de radio buttons y checkboxes deben estar contenidos dentro de un elemento<fieldset> con su correspondiente <legend>.

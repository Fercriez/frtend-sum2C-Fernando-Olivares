Reglas de Validacion Requeridas
Seccion A — Tipo de Solicitud y Datos del Evento
Campo Regla
Tipo de solicitud Debe seleccionarse una opcion (reserva o catering).
Fecha del evento No puede ser una fecha pasada. Para reservas de mesa: al menos 48
horas desde ahora. Para catering externo: al menos 7 dias desde
ahora.
Hora de inicio Para reservas de salon: solo se aceptan horarios entre las 12:00 y las
23:00.
Nombre del evento Si el tipo de solicitud es catering externo, este campo no puede estar
vacio. Minimo 5 caracteres.
Tipo de evento (catering) Si el tipo es catering, debe seleccionarse una opcion valida. Si se
elige "Otro", el campo de texto adicional no puede estar vacio.
Lugar del evento Si el tipo es catering externo, no puede estar vacio. Minimo 10
caracteres.

Seccion B — Comensales y Restricciones
Campo Regla
Cantidad de adultos Minimo 1. Para reservas de salon: maximo 20 por reserva online.
Para catering: maximo 200. Solo numeros enteros.
Cantidad de menores Minimo 0, maximo 50. No puede superar la cantidad de adultos.
Textarea de alergias Si el checkbox "Otras" restricciones esta marcado, el textarea no
puede estar vacio y no puede superar los 200 caracteres.
Cantidad de menus infantiles Si el checkbox de menu infantil esta marcado, el campo de cantidad
debe ser un numero entre 1 y la cantidad de menores ingresada.

Seccion C — Datos del Cliente
Campo Regla
Nombre completo Solo letras y espacios. Minimo 5 caracteres, maximo 80.
Correo electronico Formato valido con @ y dominio. Usar expresion regular.
Confirmar correo Debe coincidir exactamente con el campo de correo electronico Telefono Solo digitos, guiones, espacios y signo mas (+). Minimo 8 digitos
numericos.
Bebidas incluidas Al menos una opcion debe estar marcada.
Tipo de menu Seleccion obligatoria (no el placeholder).

Seccion D — Confirmacion

El textarea de observaciones no debe superar los 350 caracteres. Validar al enviar ademas
del contador en tiempo real.
Los tres checkboxes obligatorios (contacto, terminos y privacidad) deben estar marcados.
Mostrar un mensaje especifico para cada uno que falte.
